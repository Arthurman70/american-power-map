Where the data comes from, and how to add more

The built-in map is hand-curated. To grow it toward every registered business, pull from the public registries below and drop their exports on Import file; names are matched to existing centers, new ones are created and tagged with their source.

Money in politics

FEC API & bulk dataapi.open.fec.gov — every contribution, committee and independent expenditure. Export Schedule A/B CSVs from fec.gov and import directly. The FEC money button queries it live (DEMO_KEY, rate-limited).
OpenSecretsBulk data (educational license; tables for candidates, committees, PAC-to-PAC, individual contributions, lobbying by industry) and a JSON API (200 calls/day). Their industry codes are the basis for this map's industry tags. Dark-money figures here follow their 2024 analysis.
Senate LDAlda.senate.gov/api — quarterly lobbying filings: client, registrant, issues, agencies contacted. The Lobbying button queries it live.
Brennan Center / AdImpactDark-money and ad-spend totals not visible in FEC filings.
FollowTheMoney (state)followthemoney.org — state-level contributions for governors, legislators, AGs and judges.

Companies and contracts

SEC EDGAREDGAR APIs — every public company (CIK list, 10-K, ownership 13F/13D). Best route to "every listed company": import company_tickers.json converted to a nodes CSV with industry from SIC code.
USAspendingapi.usaspending.gov — federal contracts and grants by recipient and agency. Federal awards button queries it live; award-search CSV exports import directly.
IRS 990 / ProPublica Nonprofit ExplorerNonprofit Explorer API — revenue, officers and grants of 1.8M nonprofits, including 501(c)(4) dark-money groups' Schedule I grant lists.
Census County Business Patterns / BLS QCEWCounts and payroll of establishments by industry and county — the denominator for "every business in America" (~33M firms, 8M with employees).
State corporate registries / OpenCorporatesopencorporates.com — 200M+ company records with officers (API paid); Delaware and state SOS databases for LLC ownership.
GLEIF LEIgleif.org — legal-entity identifiers with parent/child ownership relationships for financial firms.

Relationships

LittleSislittlesis.org/api — the power-mapping database (boards, donations, positions, family, ownership) for 400k+ entities. The LittleSis button queries it live; JSON or CSV exports import directly.
WikidataSPARQL for officers, owners, subsidiaries and board members of companies and institutions.
Federal Register / Regulations.govWhich companies comment on which rules — regulator↔company edges.
13F / 13D filingsInstitutional ownership — the "who owns whom" layer (BlackRock, Vanguard, State Street edges) for every listed firm.

Live fetches run from your browser; some sites block cross-origin requests, in which case the CSV import path always works. This is the database-backed build: centers and arrows live in SQLite behind an API, layouts are Barnes-Hut and precomputed, and imports go to the shared database (admin token required).
